# 🚗 Car Specifications Analysis using Python

## 📌 Overview

This project explores a car specifications dataset using Python to understand feature relationships before applying Principal Component Analysis (PCA).

## 🎯 Objectives

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Descriptive Statistics
- Correlation Analysis
- Correlation Heatmap
- Feature Relationship Analysis
- Business Insights
- Understanding the Need for PCA

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Key Insights

- Engine Size and Horsepower are strongly correlated.
- Engine Size and Mileage show a negative relationship.
- Several numerical features are redundant.
- PCA can help reduce dimensionality while preserving important information.
